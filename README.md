## Production Work at Presta Technologies

These are not portfolio projects. These run in production across 120+ client portfolios weekly.

- **Outstanding Loan Snapshot** — IFRS 9-aligned MySQL stored procedure computing per-loan principal, interest, fee, and penalty balances as of any historical date. Turnaround cut from 2 days to 1 hour.
- **Book Movement Arrears Report** — Weekly DPD movement engine tracking loans across 6 delinquency bands for 10M+ borrower accounts. Shows spill-in, spill-out, partial and full recoveries every Monday.
- **Loan Portfolio Rollforward** — Monthly GL bridge reconciling the loan sub-ledger to the general ledger. Accuracy improved from 10% unexplained variance to within 99.9%.
- **PAR Report** — PAR-7 through PAR-90+ ratios segmented by product, branch, officer, and vintage. Replaced a 3-hour manual Excel process per tenant per week.
- **presta-analytics** — Multi-tenant reporting microservice (FastAPI, SQLAlchemy, Docker, AWS ECR) with per-tenant database isolation. Data analysts ship their own endpoints without backend support.
